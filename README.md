# CAEA

> ⚠️ **Projet en cours de développement.** Le code peut changer à tout moment et certaines fonctionnalités sont incomplètes. Ne l'utilisez pas en production tel quel.

Un site web pour afficher les résultats du CAEA.

## Développement

Pour commencer à développer, installez PHP et Composer, puis exécutez `composer install` depuis la racine du projet dans un terminal.

Les données réelles des élèves (`results.csv`) ne sont jamais versionnées : utilisez `results.example.csv` comme modèle.
